Help

Basics

  • Click a folder to expand or collapse it.
  • Use the search button to filter bookmarks by title or URL.
  • Ctrl-click opens a bookmark in a background tab.

Organize

  • Right-click a folder or bookmark to add, rename, edit, or delete items.
  • Drag items to reorder them or move them into another folder.
  • Folder styles are stored separately from Chrome bookmarks.

Actions

  • Find duplicate bookmark URLs locally.
  • Review folder paths before deleting.
  • Deletion requires confirmation.

Settings

  • Adjust theme, font size, spacing, zoom, and click behavior.
  • Restore Defaults resets WideMark settings only.

Privacy

  • No website host permissions.
  • No hidden tab scanning.
  • No bookmark upload.
